# Crypto-portfolio

Трекер крипто-инвестиций, чтобы не считать всё вручную в экселе и не забывать, по какому курсу была покупка.

## Что умеет

- Подтягивает актуальные курсы BTC и ETH с CoinGecko (обновляется каждую минуту)
- Считает прибыль/убыток по каждой сделке и по портфелю в целом
- Показывает комиссии обменника (это больная тема, поэтому отдельно)
- Рисует графики: распределение портфеля, динамику, историю курсов
- Есть прогноз на неделю (линейная регрессия, не воспринимать как финансовый совет)
- Калькулятор "что если" — прикинуть, что будет если курс дойдёт до X
- Можно переключать валюту: рубли, доллары, евро
- Данные хранятся в Google Таблице, так что с любого устройства всё видно

## Как пользоваться

1. Открыть ссылку
2. Нажать "Добавить транзакцию"
3. Ввести дату, сколько потратил, сколько монет получил
4. Курс подставится сам, но можно поправить
5. Сохранить — улетит в облако

## Технологии

- Чистый HTML/CSS/JS, без фреймворков
- Chart.js для графиков
- CoinGecko API для курсов
- Google Apps Script как бэкенд (да, это костыль, но работает)
- GitHub Pages для хостинга

## Что не так

- Иногда CoinGecko тупит и курсы не грузятся — подождать минуту
- Прогноз на 7 дней очень примитивный, реальный курс почти всегда идёт своей дорогой
- Нет авторизации — кто знает ссылку, тот видит данные
